01 / SOURCE–FILTER SYNTHESIS

从手腕转动，到竹筒里的空气开始共鸣。

01

旋转与张力

角速度产生周期运动，绳长与离心状态共同改变接触压力。

T ∝ mω²r
02

粘滑摩擦

涂松香的接触点经历粘住、蓄力、滑动与复位，形成尖锐脉冲和摩擦宽带。

stick → load → slip → reset
03

绳上传递

张力脉冲沿绳到达膜面中心。实时模型保留关键激励与张紧状态。

F(t) → string tension
04

膜面模态

张紧纸膜像小鼓膜一样响应。张力提高时，共振模态整体上移。

f ∝ √(T / σ)
05

竹筒共鸣

竹筒腔体形成强烈 formant，旋转指向性再加入周期 AM，成为标志性的“哇——”。

modes → cavity → radiation

实时模型的取舍

默认合成器使用粘滑脉冲列、确定性摩擦噪声、四组膜面/腔体共振模态和旋转相位 AM。几十个 Web Audio 节点即可实时运行，并让材料参数保持连续可交互。

物理依据

竹蝉结构与“绳—松香摩擦 → 膜振动 → 筒内空气共鸣”参考台北科学日实验说明；粘滑激励参考弓弦接触研究中的非线性摩擦与脉冲模式。

import {
  mountBambooCicada,
  SynthCicadaVoice,
} from 'zhuzhiliao';

const voice = new SynthCicadaVoice({
  friction: 1.2,
  membraneTension: 1.1,
  tubeLength: 140,
});

mountBambooCicada({
  voice: () => voice,
  physics: { ropeLength: 132 },
});
