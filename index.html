01 · 手腕与绳

一圈，三十多次摩擦

旋转建立张力。涂松香的接触点连续经历粘住、蓄力、滑开与复位。

78 / 2.367 ≈ 33 events / turn
02 · 不规则激励

每次都略有不同

脉冲间隔带着约 25% 抖动，摩擦宽带填入细小毛刺，让声音保持自然活性。

renewal impulses · CV ≈ 0.25
03 · 膜与竹筒

直达声里，混进一截空心回响

膜面声先经过 1863.85 Hz 辐射高通；另一支在 108.86 mm 竹筒内传播、损耗并往返反射，再由管口反相叠回。

L / c = 0.317 ms · round trip = 0.635 ms
04 · 盛夏的远近

转一圈，声音呼吸一次

一次与二次旋转调制叠加，模拟张力、耦合和辐射方向共同造成的「哇——」起伏。

AM₁ = .66 · AM₂ = .35

为什么听起来更像真的

共振衰减只有几毫秒，声音靠每秒约 78 次摩擦持续重燃。小膜辐射高通压住 300–800 Hz 的浑浊低频；反射 0.40、损耗 1.50、耦合 0.45 的弱竹筒路径，则把空心感放进相位与短脉冲尾里。

02 / 带一只竹知了回去

挂进任何网页，夏天就开始了。

默认 renderer、绳系物理与拟合声学模型开箱即玩。知了 DOM、竹棒 DOM、声音、renderer 和物理参数都可以独立替换。

pnpm add zhuzhiliao

import {
  mountBambooCicada,
  SynthCicadaVoice,
} from 'zhuzhiliao';

const voice = new SynthCicadaVoice({
  friction: 1.2,
  membraneTension: 1.1,
  tubeLength: 140,
});

mountBambooCicada({
  voice: () => voice,
  physics: { ropeLength: 132 },
});
